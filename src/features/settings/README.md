# 회원별 테마 설정

`설정 → 화면 테마`의 선택을 기존 `profiles.theme`에 자동 저장한다. 별도 저장 버튼이나 DB migration은 없다. 다음 로그인/앱 재시작에서는 서버 값을 불러오며, 앱 복귀/웹 포커스에도 재조회한다. 같은 서버를 사용하는 기기는 같은 회원 설정을 공유한다.

`ThemePreferencesProvider`는 인증 컨텍스트 안에서 화면 이동과 독립적으로 동작한다. `store`의 회원 범위는 인증 변경 즉시 화이트로 초기화하고 세대 번호를 올린다. `controller`는 회원/세대/요청 버전을 모두 확인해 계정 A → B → A 복귀나 해제 뒤 도착한 결과를 버린다. 읽기 전에 기본 테마를 서버에 쓰지 않는다.

선택 시 즉시 미리 적용하고 저장 동안 중복 선택을 막는다. 포커스 재조회는 저장을 덮지 않는다. 실패하면 마지막 확인된 색상으로 돌아가 안내하며 다시 불러오기로 실제 저장 결과를 확인한다. 응답 유실은 서버 커밋 여부를 확정할 수 없으므로 저장됐다고 표시하지 않는다. 15초 요청 중단과 화면 아닌 인증 수명의 controller를 사용한다.

service는 시작 세션의 토큰에 고정해 본인 profile만 읽고 theme 컬럼만 수정한다. 서버 RLS/기존 enum 제약을 유지한다. 이름·통화 등 다른 프로필 값은 수정하지 않는다. 다른 기기의 동시 선택은 서버에 마지막 저장된 값이 적용되며 실시간 구독은 없다. 네트워크 없이 재실행하면 서버 테마를 읽을 수 없어 기본색과 재시도 안내를 사용한다.

검증 기록은 `docs/THEME_PERSISTENCE_VALIDATION.md`를 참조한다.
