# 통계 모듈 계약

I01: `wardrobe_insights`는 기준일과 전체/최근 30일/90일을 받는 security invoker 읽기 RPC다. 날짜는 사용자 지역 달력 문자열이며 기준일을 포함한다. 기준일 이후와 삭제된 착용 이벤트는 제외한다. 같은 날의 별도 이벤트는 각각 집계한다. 현재 의류 수/상태/브랜드·대분류·구매가는 휴지통 제외 등록 의류 기준이며 판매/기부 상태도 포함한다. 기간을 바꿔 과거 옷장 상태를 재구성하지 않는다.

이벤트 수/기록 일수/의류 착용 수는 과거 스냅샷 기준이며, 나중에 휴지통으로 옮긴 옷의 기록도 포함한다. 현재 의류 중 기간 내 기록된/기록 없는 수와 누적 기록 없는 수는 현재 등록 의류 기준이다. 실제 미착용을 추론하지 않는다.

`insight_item_stats`는 의류별 기간 횟수/기준일까지 누적 횟수·마지막 기록/누적 착용당 비용을 반환한다. 비용 분모는 기간 선택과 무관한 기준일까지 전체 기록이다. 가격 미입력 또는 누적 0회는 null, 알려진 0원은 유효한 값이다. 현재 구매가를 사용하며 원화 구매가 합계와 입력 건수를 표시한다. null 가격은 합계에서 제외한다.

통계 요약은 PostgreSQL 안에서 전체 의류 관계를 집계해 API 최대 행 수에 잘리지 않는다. 대분류는 하위 카테고리를 합치고 브랜드 상위 10개와 나머지 의류 수를 반환한다. 목록은 많이 기록한 옷/기간 내 기록 없는 옷/최근 등록/전체 모드와 이름·브랜드 리터럴 검색, 안정 정렬, 20개 서버 페이지/재집계를 제공한다.

`model.ts`는 기간/날짜/응답 계약/금액 표시, `repository.ts`는 세션 확인·시작 토큰 고정·취소, `queries.ts`는 회원/기준일/기간/목록 조건별 캐시를 담당한다. 의류 생성/변경과 착용 쓰기가 insights 조회를 취소·무효화한다. 포커스와 수동 새로고침도 제공한다. `/insights`의 `InsightsScreen`은 지표/원화 금액/분포 막대/의류별 목록과 실제 빈 데이터·로딩·오류를 표시한다. 최신 검증은 `docs/PHASE_12_VALIDATION.md`다. 실제 브라우저·실기기 검증은 사용자 요청으로 보류다.
