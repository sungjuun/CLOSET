# CLOSET 프로젝트 현황

기준일: 2026-11-03 (Asia/Seoul). 현재 코드·운영 설정을 기준으로 정리했습니다. 과거 단계 문서는 해당 시점의 기록입니다.

## 제품 상태

- 웹 주소: https://closet.itsmesungjun.chatgpt.site
- 기술: Expo 58 / React Native / TypeScript / Expo Router / TanStack Query / Supabase PostgreSQL 17·Auth·Storage.
- 사이트는 소유자 전용, CLOSET 로그인은 이메일·비밀번호 방식입니다. 공개 가입은 닫혀 있습니다.
- 이메일 인증은 켜져 있습니다. 외부 인증 메일 SMTP와 Cloudflare Turnstile의 실제 계정·키 연결은 남아 있습니다.
- 운영 DB에는 겹쳐 입기와 회원별 사용량 한도 migration까지 적용되어 있습니다. 사용량 화면과 공개 가입 준비 코드는 이번 정리본에 포함합니다.

## 공개 가입 준비 상태

구현된 코드는 웹 CAPTCHA, 네이티브 WebView 연결, 가입/로그인/재설정 토큰 전달, 인증 메일 재요청·대기 시간, 서버 가입 가능 여부 표시를 포함합니다. 공개 번들에는 실제 공개 사이트 키만 허용하고 비밀 키는 포함하지 않습니다.

남은 연결 순서는 [공개 가입 안내](PUBLIC_SIGNUP.md)를 따릅니다. SMTP 미설정, 실제 CAPTCHA 미연결 상태를 가입 완료로 취급하지 않습니다. 현재 사이트 공개 범위도 변경하지 않습니다.

## 보존·제외 사항

- 기존 회원 자료·코디·사진과 착용 스냅샷을 보존합니다. 종류는 아우터/상의/하의/신발/가방/액세서리 6종이며 기존 원피스 구성은 호환 보존합니다.
- 카테고리 사용 여부 토글, 옷장 색상 드롭다운, 공지·메모·마네킹은 제거한 기능입니다.
- 추천 엔진은 슬롯당 한 벌 조합을 유지합니다. 추천을 저장한 뒤 편집기에서 레이어를 추가할 수 있습니다.
- 유료 AI·가상 착용 API는 사용하지 않습니다.

## 검증 범위

2026-11-03 타입 검사·ESLint·단위 테스트 203개, 로컬 DB/Auth/Storage 통합 167개(Node 13 + Vitest 154), Android/iOS JS export가 통과했습니다. 웹은 배포 시 공용 연결 빌드와 비밀 값 검사를 수행합니다. 테스트 계정/사진은 별도 fixture만 사용합니다. 웹 배포의 최종 결과와 커밋은 작업 완료 보고에 기록합니다.

PC·모바일 웹의 주요 화면과 320/390px 배치를 확인했고 사용자가 휴대폰 웹 정상 동작을 보고했습니다. 네이티브 실기기 카메라·공유·CAPTCHA WebView, 실제 외부 수신자의 인증 메일 및 운영 CAPTCHA 성공 흐름은 추가 검증 대상입니다.
