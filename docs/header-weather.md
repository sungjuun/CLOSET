# 헤더 날씨

- 로그인한 화면의 헤더 오른쪽에 실제 예보를 표시한다. 데스크톱은 기온·날씨·지역·체감온도, 작은 화면은 아이콘·기온을 표시한다. 누르면 헤더 아래에서 최고/최저·오늘 최대 강수확률·현재 풍속·옷차림 힌트를 확인한다.
- 기본 지역은 서울이다. 주요 도시 선택 또는 국내 시·군 검색으로 변경한다. 위치 권한이나 GPS 없이 선택한 도시 좌표만 날씨 제공자에게 전송한다.
- 지역과 추위 민감도는 계정별로 현재 기기에 저장한다. 웹은 localStorage, 앱은 SecureStore를 사용한다. 다른 기기에는 동기화하지 않는다.
- Open-Meteo의 현재 예보와 일별·시간별 예보를 HTTPS로 조회한다. 인증 토큰·쿠키를 전달하지 않는다. 10분 캐시, 15분 갱신, 12초 요청 제한을 적용한다. 조회 실패 시 재시도를 제공하고, 90분 이상 지났거나 날짜가 지난 값으로 옷차림을 안내하지 않는다. 누락 값은 `—`로 표시한다.
- 옷차림은 체감온도(없으면 기온)에 추위 민감도 ±3°C를 적용한 참고용 규칙이다. 바람을 체감온도에서 다시 차감하지 않는다. 강수·눈·결빙·바람·일교차에 따라 추가 힌트를 최대 3개 표시한다. 실제 보유 의류를 조합하는 코디 추천과는 별개다.
- 현재 값은 관측소 실측이 아닌 날씨 모델 예보다. 강수확률은 하루 중 최대값이며, 옷차림 힌트에는 향후 6시간 강수확률도 반영한다. 기준 시각은 선택 지역의 현지 시각으로 표시한다.

공식 문서: [Weather Forecast API](https://open-meteo.com/en/docs), [Geocoding API](https://open-meteo.com/en/docs/geocoding-api), [이용 조건](https://open-meteo.com/en/terms). 개인 비상업용 무료 API를 사용하며, UI에 Open-Meteo 출처 링크를 제공한다. 상업 서비스로 변경할 때 이용 조건을 다시 확인한다.

검증: `npm run check`, `npm run export:native -- --output-dir test-results/weather-native`, 호스팅 웹 빌드. `tests/weather.test.ts`는 날짜 경계, 단위, 누락값, 예보 신선도, 옷차림 조건, 실패·취소·시간 제한, 지역 검색, 저장 설정 유효성을 검사한다.
