# 회원별 테마 저장 — 2026-10-29

사용자 요청의 추천 기능 1번인 테마 설정 저장을 구현했다. 기존 메모리 전용 테마를 기존 `profiles.theme`와 연결했다. 화이트/베이지/브라운을 선택하면 자동 저장하고 다음 로그인/앱 재시작에서 복원한다. 테마 변경 위치는 설정 화면에 유지한다.

- 인증 수명의 provider/controller를 사용해 설정 화면을 벗어나도 진행 중 저장을 유지한다. 로그인 복원과 앱 복귀/웹 포커스 시 서버 테마를 불러온다. 테마 읽기 때문에 앱 전체 진입을 대기시키지 않는다.
- 계정 변경 즉시 이전 테마/상태를 초기화한다. 회원/세대/요청 버전 대조와 요청 중단으로 늦은 읽기·저장을 폐기한다. 시작 토큰과 본인 profile ID에 고정한다.
- 초기 조회 전에 기본값을 쓰지 않는다. 저장 중 연속 요청과 포커스 재조회가 선택을 덮지 않게 한다. 실패 안내와 마지막 확인 색상 복구, 실제 서버 값을 다시 읽는 버튼을 제공한다. profile의 이름·통화는 유지한다.
- DB migration/타입 재생성/환경 변수/새 패키지는 필요하지 않다. 기존 profile RLS, 수정 컬럼 권한과 세 테마 제약을 재사용한다. 원격 DB 작업/배포는 하지 않았다.
- 단위 테스트 104개와 TypeScript/ESLint 통과. 새 6개 시나리오는 복원·자동 저장·중복 선택/포커스 경합·읽기/쓰기 실패·응답 유실·A→B→A·늦은 요청/해제·재시작을 확인한다.
- 새 실제 DB 4개 시나리오에서 새 클라이언트 로그인 후 저장값 복원, 세 색상, 다른 프로필 값 유지, 회원 분리/타인 수정 차단/유효하지 않은 색상, 토큰 전환, 응답 유실/취소를 검증했다.
- 전체 실제 DB 회귀 113개(Node 13 + Vitest 100) 통과. fixture 계정/데이터만 생성하고 정리했다.
- 웹·Android·iOS export 통과. 공개 웹 산출물 34개에 로컬 서버 키가 포함되지 않았음을 확인했다. native export는 실기기 실행 검사와 구분한다.
- 실제 브라우저·실기기 조작/외관·기기간 갱신 검증은 기존 보류 상태를 유지한다. 테마는 서버 저장이며 오프라인 재실행의 로컬 캐시는 제공하지 않는다.
