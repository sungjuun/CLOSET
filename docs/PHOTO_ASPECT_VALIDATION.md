# 옷 사진 전체 표시 — 2026-10-29

사진이 잘리지 않아야 한다는 최신 요청에 따라 PhotoFrame의 cover 표시를 contain으로 변경했다. 비율을 늘이거나 자르지 않고 사진 전체를 표시한다. 상세·목록·코디·착용 기록·썸네일에 공유 적용한다. 고정 비율 카드에서는 원본과 칸 비율이 다르면 여백이 생길 수 있으며, 전체 사진 보존을 우선한다.

이후 회색 띠 개선 요청으로 고정 프레임의 남는 공간에 사진 모서리 배경을 연장했다. 원본 전체 표시 원칙은 유지한다. 현재 배경 처리와 실제 사진 비교는 `PHOTO_BACKGROUND_VALIDATION.md`를 참조한다.

상세 PhotoManager의 큰 사진은 naturalAspect를 사용한다. Image.getSize로 파일의 실제 가로/세로를 읽고 프레임 비율을 맞춰 불필요한 띠 여백을 줄인다. 매우 긴 사진은 프레임 높이를 720px로 제한하되 contain으로 전체 사진을 유지한다. 비율을 읽기 전이나 조회 실패 시에도 기본 프레임에서 전체 이미지를 표시한다.

크기는 storage_path별로 유지해 signed URL 갱신마다 다시 읽지 않는다. 사진 교체/화면 해제 뒤 늦은 크기 응답을 폐기한다. 기존 사진과 업로드 파일, DB, 브랜드용 별도 이미지 처리에는 변경이 없다. 옷 사진 업로드는 기존 preparePhoto의 원본 비율 보존 기본 경로를 그대로 사용하므로 기존 사진도 재등록 없이 전체 표시가 가능하다.

새 패키지/환경 변수/migration은 없다. 실제 브라우저/실기기 외관·디코딩 조작 확인은 기존 보류 범위를 유지하며 코드·번들 검사와 구분한다.

TypeScript/ESLint와 단위 테스트 112개, 웹·Android·iOS export를 통과했다. 공개 웹 산출물 34개에 로컬 서버 키가 포함되지 않음을 확인했다. 저장 파일과 DB를 수정하지 않아 DB 쓰기 회귀 검사를 추가하지 않았다.
