- 실패한 업로드, 교체한 로고, 과거 코디 이미지 자동 수거와 보관 기간 정책.

## 선택 가능한 기능 확장

- 상품 링크에서 상품명·브랜드 등을 추출하고 확인 후 등록.
- 자동 추천에도 셔츠+니트, 재킷+코트 레이어 적용.
- 날씨 기반 추천, 세탁/수선 상태, 미래 코디 예약, 여행 준비물, 구매 후보·의류 실측.

위 확장 후보는 우선순위와 범위를 정한 뒤 진행합니다. 이미 제거한 마네킹·공지·메모를 남은 작업으로 다시 넣지 않습니다.
