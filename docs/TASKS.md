# 개발 작업 목록

작업 단위는 아래 수락 조건까지 완료하고 검증한 뒤 다음 항목으로 진행한다. 일정 약속이 아닌 의존 순서다.

추가 UI 요청 완료: 업로드 이미지 기준 공통 헤더/모바일 상단 탐색/의류 카드와 저장 코디 읽기 목록을 반영했다. 타입/단위60개/통합41개/웹·네이티브 export 검증은 `UI_REFRESH_VALIDATION.md`, 파일 감시 보완은 `WEB_PERFORMANCE.md`를 참조한다. 원자적 코디 쓰기는 계속 O02 후속이다.

현재: F00/F01 및 로컬 A01/A02, 옷장 범위 A04/W01–W04에 이어 O01 코디 슬롯 초안 편집을 구현했다. 활성 의류 선택/교체/제거/상태 재검사/미저장 이탈 확인을 웹/API로 검증했다. 코디는 메모리에만 유지하고 DB 직접 쓰기는 닫아 두었다. A03 공개 가입 완주와 네이티브 실기기/기기간 동기화는 남아 있다. 다음은 O02 원자적 코디 저장·수정·복제·삭제다. 최신 근거는 `PHASE_07_VALIDATION.md`를 참조한다.
