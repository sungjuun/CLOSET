# 다크 모드

2026-10-29. 설정 → 일반 → 화면 테마를 화이트 / 베이지 / 다크 모드로 변경했다.

- 다크 배경, 카드, 보드, 입력, 본문·보조 문구와 링크 색을 공통 토큰으로 제공한다. 오류 안내에는 테마별 danger 색을 사용하고 로고는 기존 파란색을 유지한다. 의류 사진과 브랜드 로고 원본은 변환하지 않는다.
- 기존 회원별 테마 저장·동기화·오류 복구·로그아웃 격리 구조를 재사용한다. 브라우저의 color-scheme / theme-color와 모바일 StatusBar도 테마를 따른다. 기기의 자동 테마 전환 기능은 추가하지 않았다.
- `20261029060000_dark_theme.sql`이 기존 brown 설정만 dark로 전환하고 허용 값 제약을 교체한다. 이전 migration은 수정하지 않았다. 일반 설정과 RLS는 유지한다. 이전 서버의 brown 응답은 읽기 시에만 dark로 해석하며 신규 Brown 저장은 거절한다.

- 로컬 실제 DB 테스트 126개 통과. 세 테마 저장과 새 로그인 복원, 회원 경계, 익명 접근, 구 Brown 값 거절을 확인했다.
