# 세부 분류 드래그 정렬 — 2026-10-29

사용자 요청으로 카테고리 관리의 **세부 분류 순서 변경**에서 위·아래 화살표를 드래그 손잡이로 바꿨다. 왼쪽 기본 옷 종류의 기존 순서 조정은 유지한다.

- 순서 변경을 누르면 오른쪽 점 손잡이를 표시한다. 손잡이를 잡아 위아래로 끌면 이동 중인 행과 주변 행의 위치가 바뀌고, 놓을 때 전체 형제 순서를 한 번 저장한다. 같은 위치에 놓거나 취소하면 쓰기를 보내지 않는다.
- 실제 측정한 행 높이를 사용한다. 긴 이름/높이가 다른 행, 목록 경계와 연속 재정렬을 처리한다. 웹은 매번 현재 순서의 높이로 좌표를 다시 계산하며, 부모 스크롤에 따른 컨테이너 위치 변화도 보정한다.
- 저장 중에는 중복 조작을 잠그고 미리보기 순서를 유지한다. 실패하면 확인된 조회 데이터로 돌아가 안내한다. 변경된 형제 집합은 서버의 기존 순서 비교로 충돌을 감지한다. 종류 선택/종료는 드래그 중 잠그고 기존 화면 이탈 보호를 유지한다.
- 웹은 Pointer Events/capture로 마우스·터치를 처리한다. Space/Enter로 잡기/놓기, 방향키로 이동, Escape/키보드 포커스 이탈로 취소할 수 있다. touchAction을 손잡이에만 적용한다.
- 네이티브는 기존 RN PanResponder로 손잡이 터치를 처리하며 접근성 증가/감소 동작도 연결했다. 제스처 중단은 저장 없이 취소한다. 화면 해제/계정 교체 후 늦은 결과를 반영하지 않는다.
- 별도 패키지/환경 변수/DB migration 없이 기존 본인 순서 RPC와 토큰 고정/캐시 무효화를 사용한다. 화면 밖으로 자동 스크롤하는 기능은 추가하지 않았다.

## 검증

- TypeScript/ESLint, 단위 테스트 112개 통과. 새 6개 검사는 임의 위치 이동/ID 보존, 무변경·중복·잘못된 목적지, 다른 높이/경계, 큰 행과 작은 마지막 행, 주변 행 이동, 연속 정렬 좌표 재계산을 확인한다.
- 카테고리 실제 DB 통합 8개 통과. 기존 전체 순서/CAS·회원 경계·충돌·계정 전환과 새 버전 재조회 계약을 재확인했다.
- 웹·Android·iOS export 통과. 공개 웹 산출물 34개에서 로컬 서버 키 미포함을 확인했다. 개발 서버 경로/JS 응답과 드래그 코드 포함 여부를 확인했다.
- 실제 브라우저·실기기 포인터/제스처 조작 확인은 기존 보류 상태를 유지한다. 코드/번들 검사와 실제 기기 조작을 구분한다.
