# 설정 메뉴 통합 — 2026-10-29

사용자 요청으로 브랜드 등록/수정과 카테고리 관리를 전용 설정 영역으로 모았다.

추가 요청으로 PC/모바일 공통 헤더의 테마 색상 선택 버튼을 제거했다. 테마 변경은 **설정 → 화면 테마**에서 제공한다.

이후 테마를 기존 profiles.theme에 회원별 자동 저장/복원하도록 연결했다. 현재 저장 동작과 검증은 `THEME_PERSISTENCE_VALIDATION.md`가 이전 메모리 전용 동작 설명을 대체한다.

- PC/모바일 상단 메뉴의 브랜드 항목을 제거하고 마지막에 아이콘과 설정 메뉴를 추가했다. 설정의 하위 관리 화면에서도 설정 메뉴를 활성 상태로 표시한다.
- `/settings`에 옷장 관리 카드(브랜드/카테고리), 화면 테마, 기록과 정리(착용 기록/통계/휴지통), 계정/로그아웃을 배치했다. 좁은 화면에서 관리 카드는 한 열로 배치한다.
- 관리 경로는 `/settings/brands`, `/settings/categories`다. 기존 `/brands`, `/categories`는 새 경로로 이동한다. 기존 관리 화면/회원별 데이터/미저장 이탈 경고를 재사용한다.
- 관리 화면의 돌아가기 링크는 설정으로 연결한다. 옷장 필터의 카테고리 관리 링크를 제거하고 의류 폼의 브랜드 선택/해제와 설정으로 가는 바로가기를 유지한다.
- DB 스키마·환경 변수·패키지 변경은 없다. 이전 원화 전용/상세 필터 제거와 카테고리 기능은 유지한다.
- TypeScript/ESLint/단위 98개 통과. 실제 브라우저·실기기 외관/조작 검증은 기존 보류 범위를 유지한다. 경로와 번들 검증은 아래 기록으로 보완한다.
- 웹·Android·iOS export 통과. 공개 웹 산출물 34개에서 로컬 서버 키 미포함을 확인했다. 개발 서버의 설정/두 하위 관리 경로/이전 경로가 모두 HTTP 200이며 제공 JS 번들에 새 설정 화면과 경로가 포함된다. HTTP 확인은 로그인 후 화면 클릭/redirect 조작 검증과 구분한다.
