# 옷 사진의 회색 띠 제거 — 2026-10-29

원본 사진 전체를 보존하는 contain 표시와 정사각형 카드 사이에 드러나던 고정 회색 배경을 보완했다. 사진을 늘이거나 자르는 대신 **사진의 모서리 배경을 카드의 남는 공간에 연장**한다.

`PhotoBackdrop`은 기존 react-native-svg의 Image와 작은 viewBox로 좌측 상단 약 3% 지점의 미세한 배경 영역을 확대해 프레임 뒤에 그린다. 가장자리 테두리를 피하도록 안쪽을 사용한다. 앞쪽 의류 사진은 기존 contain으로 그대로 표시하며 둥근 카드 크기/정렬을 유지한다. 배경은 클릭/접근성 대상에서 제외한다. 기존 이미지 로더/캐시와 같은 signed URL을 사용하며 픽셀 API/CORS 분석/서버 이미지 가공/새 서비스는 필요하지 않다.

현재 사용자 예시처럼 단색 배경인 상품 사진에 맞는 방식이다. 원본 자체의 배경 제거/AI 생성이나 복잡한 배경의 완전한 복원 기능은 아니다. 투명 배경은 카드의 중립 배경으로 표시한다. 사진이 없는 placeholder와 상세의 원본 비율 프레임은 유지한다. 기존 업로드/원본/DB는 수정하지 않는다.

## 검증

- 실제 로컬 등록 사진 5개를 임시 signed URL로 읽어, 동일한 SVG 배경/contain 전경을 사용하는 독립 HTML 비교 화면에서 확인했다. 바지·코트 전체는 유지하고 고정 회색 띠가 사라지는 것을 브라우저 스크린샷으로 확인했다.
- 비교 이미지는 `test-results/photo-background-comparison.jpg`다. 위는 기존 고정 회색, 아래는 사진 모서리 배경 연장이다. 프리뷰는 loopback에만 제공하고 계정/옷/사진/Storage 객체를 변경하지 않았다. 서비스 키는 페이지에 포함하지 않고 signed URL은 단기 만료한다.
- 코드의 실제 앱 로그인/기기 회귀 확인과 독립 렌더링 비교는 구분한다. 네이티브 실기기 확인은 기존 보류 범위를 유지한다.
- TypeScript/ESLint와 단위 테스트 112개, 웹·Android·iOS export 통과. 공개 웹 산출물 34개에서 실제 로컬 서버 키 미포함을 확인했다. 새 패키지/환경 변수/migration은 없다. 비교용 서버/탭은 확인 후 종료하고 스크린샷만 남긴다.
