# UI 레퍼런스

2026-10-28 사용자가 후속 첨부로 전달한 WebP 원본을 파일명 그대로 보관했다. 원본 파일과 복사본의 SHA-256 일치 여부를 확인한다.

| 파일 | 화면 | 주요 참고 요소 |
| --- | --- | --- |
| [1.webp](1.webp) | PC 내 옷장 | 상단 탐색, 분류/검색/정렬, 상품 5열, 이미지/브랜드/제품명/색상 계층 |
| [2.webp](2.webp) | PC 저장한 코디 | 코디 카드 3열, 이름 편집 행, 태그/계절, 2×2 슬롯과 빈 슬롯 |
| [3.webp](3.webp) | 모바일 내 옷장 | 상품 2열, 두 분류 입력, 전체 너비 검색, 색상/즐겨찾기 행 |

출처: 사용자가 이 프로젝트의 UI 참고용으로 제공한 `Downloads/1.webp`, `2.webp`, `3.webp`. 원본 이미지는 문서 참조용이며 상품 데이터나 개별 상품/브랜드 에셋으로 분리하지 않았다. OS 상태 표시줄과 개인 로고/백업 영역은 앱 공통 UI 요구사항으로 해석하지 않는다.

화면별 분석, PRD와의 차이, 구현 시 수락 조건은 [UI_REFERENCE_REVIEW.md](../UI_REFERENCE_REVIEW.md)에 기록했다. 이미지 수신 및 설계 대조는 완료했지만 현재 준비 화면을 제품 화면과 동일하게 구현한 것은 아니다.
