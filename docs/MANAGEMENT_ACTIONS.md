# 카테고리·브랜드 관리 정리

2026-11-02 사용자 요청 반영.

- 카테고리에서 사용 여부 열·스위치·비활성 색상·안내와 토글 저장 동작을 제거했다. 새 옷 등록/편집도 과거 `is_active=false` 값 때문에 분류를 숨기지 않는다. 원피스·셋업의 기존 은퇴 처리와 삭제된 분류 제외는 유지한다.
- 카테고리와 브랜드는 공통 `IconButton`을 사용한다. 아이콘 18px, 터치 영역 44×44px, 연필/휴지통 순서와 색상을 공유한다.
- 브랜드 연필은 기존 편집 폼을 열고 휴지통은 행의 브랜드 스냅샷으로 확인 모달을 연다. 편집 중인 브랜드와 삭제 대상은 별도로 보관한다. 미저장 입력/진행 중 작업은 행 작업을 막으며 취소는 기존 편집 상태를 유지한다. 오류는 확인 모달에 표시한다.
- 브랜드 삭제의 소유권·버전 검사, 옷의 브랜드 연결 해제와 의류/사진/코디/착용 기록 보존, 로고 정리 재시도는 기존 서비스를 사용한다. DB 스키마·RPC 계약·백업 형식은 바꾸지 않는다.

타입 검사·ESLint·단위 197개, 실제 카테고리/브랜드 DB 30개, Android/iOS JS export를 통과했다. 임시 로컬 계정의 과거 비활성 상의/셔츠가 새 옷 선택지에 나타나는 것, 카테고리 스위치 0개, 브랜드 연필 편집/이름 저장·미저장 시 아이콘 차단, BROWNYARD 편집 중 POTTERY 휴지통의 대상 표시·취소를 브라우저에서 확인했다. 실제 사용자 브랜드는 삭제하지 않았다. 1280px PC와 390/320px 모바일 웹에서 가로 넘침을 확인했다. 실제 네이티브 기기의 터치/모달 검증과 JS export는 구분한다.
