# 스타일 가이드

2026-10-30. 업로드한 레퍼런스의 실제 표에 있는 6개 분야를 구현했다. 표 위의 ‘8개’ 문구와 달리 보이는 분야만 적용했다.

## 사용 흐름

- PC 상단 메뉴: 내 옷장 → 저장한 코디 → 코디 만들기 → 코디 추천 → 색상 조합 → 스타일 가이드 → 설정.
- 모바일: 기존 주요 4개 메뉴와 더보기를 같은 너비로 표시한다. 더보기에서 색상 조합·스타일 가이드·설정으로 이동한다. 하위 화면도 더보기 활성 표시를 유지한다.
- `/style-guide`: 코디 기본기·색상 이론·사이즈와 핏·의류 관리·신발 관리·소재 지식의 20개 정적 가이드. 분야 필터, 제목·본문·태그 검색(모든 검색어 포함), 결과 수, 빈 결과 안내와 초기화 제공.
- `/style-guide/[slug]`: 실천 단계·적용 예시·같은 분야의 관련 글·참고 링크·옷장/코디 만들기/색상 조합 연결. 없는 slug는 복귀 안내를 표시한다.
- 기존 테마 토큰으로 화이트·베이지·다크를 따른다. 작은 화면에서는 분야 버튼과 카드가 줄바꿈된다. 네이티브에서도 사용할 수 있도록 CSS calc 없이 실제 컨테이너 너비로 카드 폭을 계산한다.

## 콘텐츠와 데이터

코디 예시는 CLOSET 편집 제안이다. 관리·실측 참고 자료는 GINETEX, Woolmark, Levi’s, Nike, UNIQLO, REI 및 Adobe 공식 자료를 각 글에 연결했다. 제품의 취급 표시와 제조사 안내를 우선하며 일률적인 세탁 온도나 체형별 정답을 제시하지 않는다. 외부 링크 열기 실패를 표시한다.

새 테이블·환경 변수·외부 API·의존성은 없다. 인증된 기존 라우트 그룹을 사용한다. 의류·코디·회원 데이터와 기존 접근 범위는 변경하지 않는다. 메뉴와 글 연결에 NavigationGuard를 사용해 코디 편집 중 이탈 확인을 유지한다. 가이드는 `src/features/style-guide/guides.ts`에서 관리한다.

## 검증

- TypeScript, ESLint, 단위 테스트 192개 통과. 추가 5개는 검색어 AND·분야 조합, 한글 정규화, 상세 주소·관련 글, 모바일 메뉴 접근성과 활성 경로를 검증한다.
- 웹에서 분야 선택, 본문 검색, 결과 없음·초기화, 상세와 관련 글 표시, 잘못된 주소, 모바일 더보기 연결을 확인했다. 1440px PC 및 390/320px 모바일을 확인했다.
- Android/iOS JS export와 배포용 웹 빌드를 실행한다. 네이티브 실기기 실행은 이번 검증에 포함하지 않는다.
- 캡처는 Git에서 제외된 `test-results/style-guide-desktop.png`, `test-results/style-guide-mobile.png`에 보관한다. 실제 계정 데이터를 변경하지 않고 로컬 임시 계정으로 검증한 뒤 정리한다.
