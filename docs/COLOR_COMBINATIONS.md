# 색상 조합 가이드

2026-10-30. 참고 이미지의 기준 색상 선택과 두 색 배색 카드를 `/color-combinations`에 구현했다. 메뉴 순서는 내 옷장 / 저장한 코디 / 코디 만들기 / 코디 추천 / 색상 조합 / 설정이다.

- 네이비·블랙·그레이·베이지·브라운·카키·화이트 7가지 기준 색상에 각각 4개 배색과 짧은 분위기 설명을 제공한다. 기본 선택은 네이비다.
- 가이드의 고정 예시 색은 실제 저장된 의류 색과 독립적이다. 화면 테마를 변경해도 배색 견본은 원래 색을 유지한다. 옷과 코디를 조회·변경하거나 사진에서 색을 추측하지 않는다.
- 선택은 페이지 내 상태다. DB/환경 변수/외부 서비스/패키지를 추가하지 않으며 기존 로그인 보호와 미저장 이탈 방지 메뉴 링크를 사용한다.
- 넓은 화면은 색상 4열·배색 2열, 700px 미만은 색상 3열·배색 1열이다. RN 카드 폭은 측정 너비에서 간격을 뺀 후 내림하여 줄 밀림을 방지한다.
- 웹은 이름과 체크 상태를 제공하는 radio group이다. Tab으로 선택된 항목에 진입하고 방향키로 순환, Home/End로 양 끝 선택, Enter/Space로 활성화한다. 앱은 같은 데이터의 Pressable 라디오를 제공한다. 색 이름과 설명을 함께 표시해 색상만으로 내용을 구분하지 않는다.

## 검증

- TypeScript / ESLint / 기존 단위 테스트 160개 통과. Android·iOS JS export 통과(실기기 검증은 별도).
- 실제 웹에서 7개 기준 색상 선택과 결과 제목 변경, 체크 상태, 키보드 오른쪽 이동과 마지막→첫 항목 순환을 확인했다.
- 1280px에서 상단 메뉴·배색 2열 표시, 390px/320px에서 가로 넘침 없는 선택 카드와 배색 1열 표시를 확인했다.
- 다크 모드에서도 7개 견본의 실제 RGB 값이 유지되고 화면 텍스트·테두리가 테마를 따름을 확인했다. Home/End 선택, 콘솔 오류 없음과 로그아웃 후 직접 URL 접근의 로그인 이동도 확인했다.
- Supabase의 별도 임시 검증 계정으로만 확인한 후 로그아웃·계정 제거·화면 너비 복원을 마쳤다. 실사용 의류·사진은 변경하지 않았다. 검증 캡처는 Git에서 제외된 `test-results/color-guide/`에 보관한다.
