# 옷 색깔 조합하기

2026-10-30. `/color-combinations`의 단순 7색 배색표를 상의·하의 선택 도구로 교체했다.

## 화면

- 두 슬롯 모두 42색이다. 어느 쪽부터 선택해도 되고 같은 색을 다시 누르면 해제한다. 반대쪽은 직접 정한 추천 순서와 무채색·명암·색 계열 정렬을 사용한다. 전체 색 보기는 모든 선택을 허용한다. 순서 있는 1,764개 조합 모두 결과를 제공한다.
- 랜덤은 15개 시작 조합 중 현재 조합을 제외해 고른다. 초기화는 선택만 해제하고 계정의 찜은 보존한다.
- 직접 작성한 SVG 티셔츠·바지·신발을 색상에 맞춰 표시한다. 기존 의류 사진이나 외부 이미지는 사용하지 않는다. 이름·설명·태그·HEX와 대체 하의 선택을 제공한다.
- 배색 포인트는 HSL의 밝기·선명도와 명암 차이다. 피부색·퍼스널 컬러·봄웜/여름쿨 진단은 하지 않는다. 테마를 바꿔도 견본과 옷 색은 유지한다.
- 웹 방향키/Home/End는 포커스 이동, Enter/Space는 선택·해제다. 터치 영역은 최소 44px이며 작은 화면은 세로 배치한다.

## 저장·공유·비교

- 찜은 상의/하의 순서까지 계정별로 저장한다. 중복 재시도는 같은 행을 확인한다. 200개씩 조회하고 6개씩 화면에 표시한다. 시작 토큰 고정, 요청 시간 제한·취소, 성공 확인·재조회, 회원별 Query key와 로그아웃 캐시 제거를 사용한다.
- 공유 주소에는 검증된 `top`/`bottom`만 담는다. 로그인 전에는 두 색만 로그인 페이지로 전달하고, 로그인 후 같은 결과로 돌아간다. 외부 `next` URL, 사용자 ID, 찜 목록은 받거나 공유하지 않는다. 기존 사이트의 접근 범위는 유지한다.
- 웹 링크 공유는 Clipboard API와 선택 가능한 링크 표시다. 앱은 기본 공유 창을 사용한다. 실제 수신자 선택과 전송은 사용자가 한다.
- 비교는 페이지 내 최대 3개다. 중복·초과·개별 제거·전체 비우기를 처리하며 페이지 이동/새로고침하면 비워진다. 영구 보관은 찜을 사용한다.
- 웹은 SVG를 960×1600 PNG로 변환해 다운로드한다. 앱은 SVG 스냅샷을 캐시에 저장해 `expo-sharing`으로 전달하고 정리한다. 내보내기 중 중복 실행과 색 변경을 막고 실패를 표시한다.

## DB와 환경

21번째 `20261029231524_color_pair_favorites.sql`은 기본키 `(user_id,top_color,bottom_color)`, Auth 사용자 삭제 cascade, 42색 ID CHECK와 본인 전용 SELECT/INSERT/DELETE RLS를 추가한다. UPDATE 및 created_at 직접 입력은 허용하지 않는다. 회원/정렬 인덱스가 있으며 새 SECURITY DEFINER 함수는 없다.

로컬 DDL 검증 뒤 `db pull --local`로 생성한 migration을 검토했다. 관련 없는 extension 차이를 제외하고 컬럼별 INSERT 권한을 명시적으로 보존했다. 로컬/공용 DB 모두 적용했으며 생성 타입 중 새 테이블만 반영했다.

추가 환경 변수나 유료 서비스는 없다. `expo-sharing`과 config plugin을 추가했으므로 기존 네이티브 development build는 해당 모듈을 포함해 재빌드한다.
