# 카테고리 관리 A안 적용 — 2026-10-29

사용자가 세 가지 이미지 목업 중 A안을 선택해 실제 `/settings/categories`에 적용했다. 선택 목업은 `reference/category-management-a.png`에 보존한다.

## 화면과 동작

- PC 900px 이상에서는 왼쪽에 7종류 목록/종류별 실제 세부 분류 개수, 오른쪽에 선택한 종류의 관리 패널을 배치한다. 선택은 파란 강조선/아이콘으로 표시한다. 목업의 예시 수치 대신 현재 회원 데이터를 사용한다.
- 종류명/세부 분류는 기본 텍스트로 표시한다. 연필을 누르면 해당 항목만 편집하며 이름 저장/취소를 제공한다. 배경 재조회가 편집 snapshot을 덮지 않고 충돌이면 입력을 유지한다.
- 종류/세부 분류의 스위치는 즉시 저장한다. 이름 편집 중인 항목은 스위치를 잠가 편집 내용을 덮지 않는다. 사용 안 함은 기존 새 옷 등록 숨김 동작을 유지한다.
- 왼쪽 옷 종류는 순서 변경 모드에서 위·아래 버튼을 표시한다. 오른쪽 세부 분류는 이후 요청으로 드래그 손잡이로 변경했다. 놓을 때 바로 저장하며 완료는 편집 모드를 닫는다. 현재 드래그 계약은 `CATEGORY_DRAG_VALIDATION.md` 참조.
- 새 세부 분류는 선택한 종류 아래의 입력칸에서 추가한다. 상단 추가 버튼은 입력칸에 포커스를 준다. 숨긴 종류 아래에 추가해도 새 옷 등록에서는 함께 숨긴다.
- 다른 종류/다른 이름 편집으로 전환할 때 버려질 입력이 있으면 확인한다. 앱 메뉴/뒤로 가기/창 닫기의 기존 이탈 보호를 유지한다. 취소하면 입력을 보존한다.
- 좁은 화면에서는 종류 선택을 상단 SelectField로 전환한다. 종류 순서 편집 중에는 전체 종류 목록과 화살표를 표시한다. 터치 목표는 최소 44px이며 긴 이름은 줄바꿈/축약과 전체 접근성 레이블을 제공한다.

## 데이터/검증

기존 회원별 카테고리/RPC/쿼리 키/시작 토큰 고정/15초 중단/계정 경계 폐기를 재사용한다. 저장 결과를 회원별 캐시에 반영한다. 순서 저장 후에는 같은 시작 토큰으로 전체 분류와 갱신된 버전을 읽어 연속 조정의 오래된 CAS 값을 방지한다. 기존 옷·코디·착용 데이터와 DB 스키마는 변경하지 않는다. 새 환경 변수/패키지는 없다.

- TypeScript/ESLint와 단위 테스트 106개 통과.
- 카테고리 실제 DB 통합 8개 통과. 순서 변경 결과의 전체 순서와 새 버전 반환 검사를 보완했다. 기존 회원 분리/타인 연결 차단/기존 기록 보존/충돌/응답 유실/1,005개 조회/계정 경계를 확인했다.
- 웹·Android·iOS export 및 공개 웹 산출물 34개의 로컬 서버 키 미포함 검사 통과. 개발 서버 `/settings/categories`와 JS가 HTTP 200이며 제공 코드에 새 관리 컴포넌트가 포함됨을 확인했다.
- 실제 브라우저·실기기 조작/외관 확인은 기존 보류 범위를 유지한다. 번들 검증과 실제 기기 확인은 구분한다.
