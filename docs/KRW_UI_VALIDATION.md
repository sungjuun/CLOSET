# 원화 통일과 상세 필터 제거 — 2026-10-29

사용자 요청으로 가격을 원화 전용으로 변경하고 옷장 목록의 상세 필터를 제거했다. 이전 다중 통화/상세 필터 문서보다 이 결정을 우선한다.

## 변경

- 등록/수정의 통화 입력칸 제거, 구매 가격에 `(원)` 표시. 입력 스키마는 KRW만 허용하고 생략 시 KRW를 사용한다.
- 상세·가격 정렬 목록·통계 합계·착용당 비용을 공통 `formatWon`으로 표시한다. 예: `125,000원`, `0원`. 기존 금액과 평균의 소수 정밀도는 최대 둘째 자리까지 유지한다.
- 프로필 기본 통화와 의류 통화에 KRW DB 제약을 적용했다. 새 migration은 `20261029010000_krw_only.sql`이며 총 14개다.
- 기존 가격이 있는 외화 행이 있으면 임의 환산/원화 재표기 없이 migration을 중단해 검토하도록 한다. 금액이 없는 외화 행과 프로필 기본 통화만 KRW로 정리한다. 이 PC의 기존 의류/프로필은 모두 KRW여서 금액을 바꾸지 않았다.
- 가격 정렬에서 통화별 그룹을 제거했다. 미입력 가격은 마지막이며 동률의 created_at/id 순서는 유지한다.
- 목록의 상세 필터 버튼/패널과 그 안의 브랜드·계절·상태 입력 제거. 분류·검색·색상·즐겨찾기·정렬·초기화는 유지하며 휴지통은 계정 메뉴에 남아 있다. 코디의 기존 필터와 의류 추가 정보 입력은 유지한다.
- 공유 서버 필터는 코디 후보 등에서 사용하므로 삭제하지 않았다. 회원/RLS/캐시 경계는 그대로다.

## 검증

- TypeScript, ESLint, 단위 93개 통과. 외화 입력 거부, 원화 포맷·0원/미입력/착용 기록 없음 구분을 확인했다.
- 실제 로컬 DB 통합 101개 통과(Node 13 + Vitest 88). USD/EUR/JPY 직접 등록, 외화 수정, 프로필 기본 통화 변경을 DB에서 거부하고 기존 가격을 보존하는 검사를 추가했다. 300개 원화 가격 정렬, 1,005개 통계 합산과 회원 분리도 확인했다.
- SQL lint, 웹·Android·iOS export, 공개 산출물의 실제 로컬 service-role 키 미포함 검사 통과.
- 로컬 DB에 14번째 migration 적용. 테스트는 직접 생성한 임시 계정과 데이터만 사용하고 정리했다. 기존 사용자 의류/사진은 유지했다.
- 브라우저·실기기 조작/외관 검증은 기존 보류 범위를 유지해 이번에는 수행하지 않았다. native export는 실기기 빌드 검증과 다르다.

다른 PC에서는 최신 코드를 받은 뒤 `npm run db:migrate`로 원화 제약을 적용한다. 기존 외화 가격 때문에 실패하면 해당 금액을 확인해 실제 원화 금액으로 수정한 뒤 적용해야 한다. 환율이나 금액을 임의로 추정하지 않는다.
